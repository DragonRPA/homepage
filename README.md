# (주)드래곤알피에이 공식 홈페이지 (www.dragonrpa.co.kr)

B2B 업무 프로세스 자동화(RPA), 렌탈 자산/배차 관리 ERP, 국가 공공데이터포털(data.go.kr) API 데이터 파이프라인 연계 전문 기업의 공식 홈페이지입니다.

## 🚀 기술 스택
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Hosting**: Vercel / Cloudflare Edge

## 📦 시스템 구성도
- `www.dragonrpa.co.kr` : 회사 공식 홈페이지 및 솔루션 소개
- `erp.dragonrpa.co.kr` : 사내 업무용 ERP 시스템 (렌탈 자산/배차/정산)
- `api.dragonrpa.co.kr` : 공공데이터 API 및 비동기 수집 엔진

## 🛠️ 개발 및 빌드
```bash
# 로컬 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 실행
npm run start
```
